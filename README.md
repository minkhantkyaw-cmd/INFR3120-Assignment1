# FUNCTIONALITY FEATURE HIGHLIGHTS

1. Semantic Markup: Includes HTML5 elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`, `<address>`)
2. CSS Style: Implemented percentage sizing, CSS floats
3. Media: includes an mp4 video with native controls and a custom poster image on the about page.
4. Responsive viewports: implemented different css styles linked via media queries for seamless 
responsiveness across different devices.
5. Navigation: Home,Projects,Contact, About pages linked from header on every page
6. Home page: Brief Introduction and three clickable links to other pages. Hover changes the box color.
7. Project: Project boxes with title heading and a short description. Hover changes the box color.
8. Contact: Includes a form with name, email, phone number, date of birth, country, comments and two buttons; submit and reset.
9. Footer: link to email and copy right

# VIEWPORT DIMENSIONS

1. mobile.css: screen width max 480px used. This covers almost the majority of the mobile devices.
2. tablet.css: screen width from 481px to 960px used. This covers the majority of the tablets and iPads.
3. style.css: screen width from 961px and above used. This covers the majority of large computer or monitor screens.
